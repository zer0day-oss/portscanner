This is a portscanner that I've made using python, which I mostly use for CTFs. I try to build on to it as a way to learn python, so there may be errors or mistakes that beginners make. 
# Usage
```
usage: portscanner [-h] -i IP [-n]

Python script that scans all 65535 ports quickly

options:
-h, --help   show this help message and exit
-i, --ip IP  IP address to scan
-n, --nmap   Use nmap scan after discovering ports, outputting the results.
```
